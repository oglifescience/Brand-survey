# OG Derma — Brand Concept Survey

Interactive survey website for evaluating OG Derma brand packaging concepts.

- **Brand:** OG Derma (OG Life Science)
- **Product:** Acne Prone · Oily Skin · Cleanser
- **Target Audience:** Gen Z (18–25)
- **Live Preview:** GitHub Pages

## Project Structure
- `index.html` — Full-page interactive showcase (Hero, Concept A, Concept B, Survey Form)
- `style.css` — Responsive design tokens and animations
- `script.js` — Packaging flip/swipe interaction and form submission
- `.nojekyll` — GitHub Pages direct static hosting configuration
